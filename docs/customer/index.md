# tmux-trainer documentation

tmux-trainer teaches tmux by doing: one short exercise a working day,
with an automatic check that tells you whether it worked.

## Where to start

New here? Read [Getting started](getting-started.md). It walks you
through installing the tool, opening your first exercise, verifying
it, and building a daily habit. It takes about 15 minutes.

## Documents

| Document | Read it when |
| --- | --- |
| [Getting started](getting-started.md) | You are installing the tool for the first time |
| [Features](features.md) | You want to know every command, option, and setting |

## Quick reference

```bash
tmux-trainer              # today's exercise
tmux-trainer check        # verify your tmux state
tmux-trainer done         # mark the exercise completed
tmux-trainer skip         # queue it for a later review
tmux-trainer cheat        # shortcuts you have learned so far
tmux-trainer exam         # 20-minute timed drill (inside tmux)
tmux-trainer help         # full command list
```
